# Procesar por lote

1. Pulse **Procesar por lote** en la pantalla inicial o **Por lote** en la barra superior para activar el fondo violeta. Las opciones laterales permanecen visibles aunque no haya una imagen abierta.
2. Pulse **Agregar carpeta de entrada** en la franja inferior o **Elegir carpeta** en el panel lateral. Se cargarán imágenes compatibles también desde subcarpetas.
3. La carpeta de entrada aparecerá automáticamente también como salida. Puede elegir otra o pulsar **Usar la misma carpeta de cada original**.
4. Elija PNG, WebP sin pérdida, TIFF o BMP. Configure PPP si usa PNG.
5. Active las etapas necesarias con **SÍ/NO**.
6. Ajuste cada panel una sola vez; la misma configuración se aplica a toda la cola.
7. Revise las miniaturas debajo del canvas y recórralas con las flechas laterales. La franja no se arrastra con el mouse.
8. Inicie. Cada éxito se exporta y desaparece; cada error queda visible.
9. Para interrumpir, use **Detener lote**. Lo pendiente se conserva.
10. Corrija los errores y reintente.

Consejo: si no sabe si las imágenes tienen alfa parcial, mantenga Transparencias activado antes de Residuos o Pulido.
